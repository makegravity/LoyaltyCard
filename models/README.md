# Models

`ultraface-rfb-320.onnx` finds faces in card photos (`lib/faces.js`). It is the RFB-320 model from
[Ultra-Light-Fast-Generic-Face-Detector-1MB](https://github.com/Linzaer/Ultra-Light-Fast-Generic-Face-Detector-1MB)
by Linzaer, MIT licence, file `models/onnx/version-RFB-320.onnx` (1,270,727 bytes).
